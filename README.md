## 프로젝트 요약

이 프로젝트는 Unity와 C#으로 제작한 2D 덱빌딩 로그라이크 전투 시스템 프로토타입입니다.

ScriptableObject 기반 카드 데이터와 Effect 구조를 활용해 카드 효과를 조합할 수 있도록 구현했으며, 드로우 더미 / 손패 / 버림 더미 / 소멸 더미를 활용한 카드 순환 구조를 만들었습니다.

또한 플레이어 턴과 적 턴을 분리한 턴제 전투 흐름, Power 기반 상태이상 처리, 카드 키워드 툴팁, 전투 상태 UI, 전투 승리 후 카드 보상 선택 흐름을 구현했습니다.

Unity 기본 AudioSource 대신 Wwise를 연동하여 전투, UI, 카드 선택 등 게임 내 사운드를 Wwise 기반으로 관리했습니다. 또한 카드 선택 화면과 전투 화면에서는 Wwise State를 전환하여 진행 상황에 맞게 사운드 분위기가 달라지도록 구현했습니다.

## 주요 구현 기능

### 1. ScriptableObject 기반 카드 데이터 / 효과 시스템

카드 정보를 코드에 직접 작성하지 않고 `CardData` ScriptableObject로 분리하여 관리했습니다.

카드 이름, 비용, 타입, 이미지, 피해량, 방어도, 설명, 효과 목록을 카드 데이터에 저장하고, 실제 전투 중에는 카드 오브젝트가 해당 데이터를 참조하여 UI 표시와 효과 실행을 처리합니다.

카드 효과는 `CardEffect` 추상 클래스를 기반으로 공격, 방어, 유틸리티, 키워드 효과로 분리했습니다.
각 카드는 여러 개의 Effect를 가질 수 있으며, 카드 사용 시 등록된 Effect 목록을 순차적으로 실행합니다.

**구현 내용**

* 카드 데이터와 카드 오브젝트 분리
* 카드 이름, 비용, 이미지, 설명, 수치를 ScriptableObject로 관리
* CardEffect 기반 카드 효과 실행 구조 구현
* 하나의 카드에 여러 Effect를 등록하여 조합 가능
* 플레이어와 적 상태에 따라 카드 설명의 실제 수치 실시간 갱신

---

### 2. 덱 / 손패 / 버림 더미 관리 시스템

전투 중 카드 흐름을 관리하기 위해 보유 덱, 드로우 더미, 손패, 버림 더미, 소멸 더미를 분리했습니다.

전투 시작 시 플레이어가 보유한 덱을 복사하여 전투용 드로우 더미를 만들고, 이를 셔플한 뒤 카드를 드로우합니다.
카드를 사용하면 일반 카드는 버림 더미로 이동하고, 일회성 키워드를 가진 카드는 소멸 더미로 이동합니다.

드로우 더미가 비어 있을 경우 버림 더미를 다시 섞어 드로우 더미로 전환하여 카드 전투의 기본 순환 구조를 구현했습니다.

**구현 내용**

* 보유 덱 / 드로우 더미 / 손패 / 버림 더미 / 소멸 더미 분리
* 카드 드로우, 사용, 버림, 소멸 처리
* 드로우 더미가 비었을 때 버림 더미 재셔플
* 일회성, 보존 키워드에 따른 카드 처리
* DOTween을 활용한 카드 이동 애니메이션
* 손패 카드 위치 자동 정렬

---

### 3. 턴제 전투 흐름 관리

`BattleManager`를 중심으로 전투 전체 흐름을 제어했습니다.

전투 시작 시 플레이어 상태 초기화, 전투용 덱 세팅, 첫 턴 시작을 순차적으로 처리합니다.
이후 턴 종료 버튼 입력에 따라 플레이어 턴 종료 → 적 턴 시작 → 적 행동 실행 → 다음 플레이어 턴 시작으로 이어지는 전투 루프를 구성했습니다.

모든 적이 처치되면 전투 상태를 초기화하고 카드 보상 선택 화면으로 이동합니다.
이를 통해 전투 → 승리 → 카드 선택 → 덱 강화 → 다음 전투로 이어지는 기본 진행 구조를 구현했습니다.

**구현 내용**

* 플레이어 턴 / 적 턴 분리
* 턴 시작 시 카드 드로우 및 에너지 회복
* 턴 종료 시 손패 버림 처리
* 적 턴에서 적 행동 순차 실행
* 전투 승리 후 카드 보상 화면으로 전환
* 전투 ID에 따른 적 생성 및 배치

---

### 4. 공통 전투 상태 처리 구조

플레이어와 몬스터가 공통으로 사용하는 전투 상태 처리를 위해 `Damageable` 기반 클래스를 구현했습니다.

HP, 방어도, 피해 처리, 회복, 공격, 사망 판정, 상태이상 목록을 공통으로 관리하여 플레이어와 적이 동일한 전투 규칙을 사용하도록 구성했습니다.

피해를 받을 때는 방어도를 먼저 차감하고, 초과 피해만 HP에 적용합니다.
또한 힘, 약화, 취약, 손상 등의 상태값을 피해량과 방어도 계산에 반영하여 현재 전투 상태에 따라 실제 카드 효과가 달라지도록 처리했습니다.

**구현 내용**

* 플레이어 / 몬스터 공통 전투 상태 처리
* 방어도 우선 차감 후 HP 피해 적용
* 공격력 증가, 약화, 취약, 손상 상태를 피해 / 방어 계산에 반영
* HP 변화 이벤트를 통한 UI 갱신
* 데미지 팝업 및 피격 / 사망 애니메이션 연동

---

### 5. Power 기반 상태이상 시스템

버프와 디버프를 `Power` 추상 클래스로 정의했습니다.

각 Power는 아이콘 이름, 표시 이름, 설명, 수치, 적용 로직, 중첩 로직, 제거 로직을 가집니다.
상태이상은 전투 대상의 Power 목록에 추가되며, 이미 같은 Power가 존재하는 경우 신규 적용과 중첩 적용을 구분하여 처리합니다.

예를 들어 화상 상태는 적 턴 시작 이벤트에 반응하여 대상에게 직접 HP 피해를 주고, 수치를 감소시킨 뒤 0이 되면 자동으로 제거됩니다.

**구현 내용**

* Power 추상 클래스를 통한 상태이상 공통 구조 정의
* OnApply / OnAdded / Remove 로직 분리
* BattleEvents를 활용한 턴 이벤트 기반 상태이상 처리
* 화상 상태의 턴 시작 피해, 수치 감소, 자동 제거 구현
* Power 정보를 상태 아이콘과 설명 UI에 연결

---

### 6. 카드 키워드 및 전투 UI

카드에 마우스를 올렸을 때 카드가 확대되고, 카드가 가진 키워드의 이름과 설명을 툴팁으로 표시하도록 구현했습니다.

일회성, 보존 같은 키워드는 단순 설명에 그치지 않고 실제 카드 처리 로직에도 사용됩니다.
예를 들어 일회성 카드는 사용 후 소멸 더미로 이동하고, 보존 카드는 턴 종료 시 손패에 남습니다.

전투 UI에서는 HP, 방어도, 상태이상 아이콘, Intent 아이콘, 피해량 팝업을 표시합니다.

**구현 내용**

* 카드 키워드 툴팁 표시
* 일회성 / 보존 키워드 처리
* HP / 방어도 UI 갱신
* 상태이상 아이콘 및 설명 패널 표시
* 적 Intent 아이콘 표시
* 피해량 팝업 피드백 구현

### 7. 카드 보상 및 Wwise 연동

전투 승리 후 카드 보상 선택 화면을 구현했습니다.

보상 화면에서는 랜덤으로 3장의 카드 후보를 제시하고, 한 번의 선택 화면 안에서는 중복 카드가 나오지 않도록 처리했습니다.
플레이어가 카드를 선택하면 해당 카드가 보유 덱에 추가되며, 선택이 끝나면 다음 전투가 시작됩니다.

또한 Unity 기본 AudioSource 대신 Wwise를 연동하여 게임 상태에 따른 사운드 전환을 구현했습니다.
카드 선택 화면에 진입하면 Wwise State를 `Card_Select`로 변경하고, 전투가 시작되면 `Battle` State로 전환하여 게임 진행 상태에 따라 BGM의 음향효과가 달라지도록 처리했습니다.

**구현 내용**

* 전투 승리 후 카드 선택 보상 화면 표시
* 랜덤 카드 3장 제시 및 중복 방지
* 선택한 카드를 플레이어 보유 덱에 추가
* 카드 선택 종료 후 다음 전투 시작
* Wwise State를 활용한 카드 선택 / 전투 상태 전환
